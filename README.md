# Sales_Analysis
End-to-end sales analysis using Python, Pandas, MySQL, SQL &amp; Power BI.

# Project Overview
This project takes raw sales transaction data and transforms it into a cleaner, analysis-ready dataset.

The workflow includes:
-Raw sales data stored in Excel

-Data cleaning and transformation using Python and Pandas

-Derived columns for Profit, Year, and Month

-Cleaned data export to CSV

-Loading the cleaned dataset into MySQL

-Sales analysis and visualization using Power BI

-The raw dataset contains 500 rows and 7 columns. After cleaning, the analysis-ready dataset contains 482 rows and 10 columns.
